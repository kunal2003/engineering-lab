# Engineering Lab — Kunal Matta

Three small, working systems that expose their decisions and failure modes. Built in September 2026 with Codex assistance; experimental prototypes, not production deployments.

| Project | Try it | Source | What it proves |
|---|---|---|---|
| Precision Lab | Change storage precision, classify a point, benchmark your device | [Design](docs/precision.md), [core](core/precision.ts) | Reproducible training, binary serialization, quantified storage tradeoffs |
| Local Lens | Upload text and inspect ranked passages with line citations | [Design](docs/local-lens.md), [core](core/retrieval.ts) | Deterministic local retrieval and evidence boundaries |
| Signal | Skip, duplicate, and recover baggage scans | [Design](docs/signal.md), [core](core/signal.ts) | Replayable state, idempotency and recovery under incomplete events |

## Run the core

Node 24 or later. No npm dependencies needed.

```sh
node --test tests/core.test.mjs
node scripts/benchmark.mjs
```

Retrain the neural network with Python 3 and NumPy:

```sh
python3 -m pip install numpy==2.3.5
python3 scripts/train.py
node scripts/benchmark.mjs
```

Training and test data are synthetic, seeded and generated by the training script. `data/training.json` records seeds, loss and model SHA256. `data/benchmark.json` records the runtime, processor and raw timing trials. Binary models are generated by the benchmark script.

## Website

`web/` contains the interactive Next.js portfolio and shared core copies. Install with `npm install`, then `npm run dev`. `npm run build` produces static output under `out/`. No backend or API key is required. The downloadable personal résumé is distributed separately from this repository. Core edits must be copied to `web/lib/lab/` before building.

## Evidence and boundaries

8 automated tests cover retrieval provenance and abstention, duplicate document ids, unordered scans, gap recovery, bag isolation, packed model round trips and malformed bytes. All three precisions classify 512/512 held-out points correctly on this narrow synthetic task. The 32/8/4-bit files occupy 1,460/500/340 bytes respectively, including metadata and float32 biases. This is **not** an LLM, GPU benchmark, production RFID integration, or general search-quality claim.

Next work: additional distribution-shift datasets; browser benchmark variability; retrieval evaluation against independently labelled queries; durable scan ingestion and a conflict policy for mismatched duplicate IDs. I need to understand and defend each design before presenting it as engineering experience.
